# Футбольный датасет

Полный архив: [football_dataset.zip](football_dataset.zip).

33 011 матчей пяти лиг: АПЛ, Бундеслига, Ла Лига, Серия A и Лига 1.
Даты: 15.08.1992–02.11.2026; начало истории отличается между лигами.
Проверено 05.11.2026 по доступным публичным снимкам. Следующие игры
в снимке расписания пяти лиг указаны с 06.11.2026; независимая проверка
официальных протоколов не выполнялась.

Внутри: результаты, исторические признаки для обучения, исходные архивы,
скрипты сборки и проверки, отчёты покрытия и сверки, условия использования.
Составов, xG и подробных игровых событий в обучающих таблицах нет.

Первоначальные источники OpenFootball/FootballCSV используют CC0.
Дополнения из open-matchday и зеркал Football-Data имеют другие условия,
включая некоммерческое использование и атрибуцию. Весь объединённый
датасет нельзя обозначать CC0. Подробности и ссылки находятся внутри архива.

Контрольная сумма архива: `SHA256SUMS`.
